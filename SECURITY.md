# Security

## Reporting Vulnerabilities

This is a personal, experimental project. If you discover a security issue, please open a GitHub issue or contact the maintainer directly.

## Threat Model

See [THREAT_MODEL.md](THREAT_MODEL.md) for a full description of:

- Threats the system explicitly defends against (compromised manager wallet, unauthorized Envelope callers, reentrancy, etc.)
- Threats that are out of scope (compromised admin key, frontend compromise, USDC blacklisting, etc.)
- Assumptions the system relies on

## No Audit

This project has not been audited. See the caution notice in [README.md](README.md).
